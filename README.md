# 侧栏分类

将 DeepSeek Harness 左侧功能入口分为「工作 / 管理 / 开发」，保留原有工作区、会话、设置和新建会话。

## 安装与使用

在 **插件 → 添加插件** 中安装本目录，或安装交付的 tgz 文件。刷新界面后，新建会话按钮下方显示分类。

- 工作：自动化任务、任务看板、个人办公，以及暂未识别的新入口。
- 管理：插件、技能中心。
- 开发：终端、调试、Forge 等开发入口（安装后自动识别）。
- 分类右侧按钮可修改每个入口的分类，立即生效；「恢复默认分类」清除自定义归类。
- 分类与上次选择保存在当前浏览器的 localStorage，不跨设备同步。
- 支持鼠标、Tab、左右箭头、Home/End，以及 Escape 关闭分类设置。
- 收起侧栏时使用原有图标导航；展开后恢复分类。
- 原导航的固定规则继续生效；「更多」保留所有未固定入口，不受分类筛选，方便随时找到入口。
- 如果不同入口使用完全相同的显示名称，它们会在所有分类中显示，避免误隐藏。

## 兼容性与回退

针对 **DSH 0.2.2-rc.3**。在官方 `sidebar.session.action` 扩展位中注册分类控件，按实时导航元数据生成样式筛选规则；使用 `data-sidebar-scrollport` 标记与入口无障碍名称定位导航行。不替换侧栏，不改安装包，不修改 Agent 预设，不添加工具或网络访问。

依赖本版本侧栏的导航行结构；DSH 升级后需要重新验证。停用或卸载本插件并刷新，即恢复原始导航。当前分类控件依附新建会话入口，没有创建会话权限的环境不在支持范围内。空分类可能只显示「更多」，可使用分类右侧按钮调整入口归属。

## 验证状态

已通过构建、JavaScript 语法检查、5 项自动检查（分类及配置回退、CSS 转义与同名入口保护、当前安装版本真实 SlotCore 中的注册与卸载、元数据和主题变量），以及当前 DSH Loader 对 bundle 补丁的解析验证。

尚未在用户的 DSH 中安装；当前环境未获准控制 DeepSeek Harness 窗口，因此实际显示、鼠标/键盘交互、深浅主题切换仍需安装后验证。此包为供试用的第一版。

## 开发

源代码在 `src/`。当前工作区构建工具复用相邻 `deepseekharnessplugin/node_modules` 中的 esbuild，运行 `node tools/build.mjs`。安装使用 `lib/client.js`，不依赖开发工具或相邻目录。测试运行 `node --test tests/*.test.mjs`。
